# **App Name**: LabourChok

## Core Features:

- Customer Profile Creation: Customers are able to create profiles
- Worker Profile Creation: Workers create detailed profiles including name, mobile number, experience, location, primary skills (from a list), secondary skills (free text), and desired daily wage.
- Separate Dashboards: Workers and Customers have separate dashboards
- Intelligent Job Matching: AI-powered tool matching workers to jobs based on skills, experience, location, and desired wage.
- Real-time Navigation: Workers can navigate to job locations using in-app real-time navigation. Integrates with the phone's default navigation app.
- In-App Hiring/Payment Flows: Customers can hire workers directly through the app, manage job progress, and process payments securely.
- AI Assistant Chatbot: In-app AI chatbot to assist with onboarding, answer questions, and provide support for both customers and workers. The tool should know about onboarding.
- Multi-Language Support: The application will support multiple languages including English, Hindi, and Bengali via text translation. User selects preferred language during profile creation. Google Translate API can be used for implementation.
- Direct Hire: Workers can be directly hired by customers if available

## Style Guidelines:

- Primary color: Golden green (#FFC107). Taking inspiration from the 'Karma' aspect of the application's name, and by extension 'gold,' but aiming for a warmer and more accessible tone rather than extravagance. A golden yellow lends the app an aura of promise, and a sense of reliability.
- Background color: Very light blue(#FAF9F0). A neutral backdrop ensures legibility of primary text and images, avoids distraction, and gives a clean feel. At the same time, it retains a subtle connection to the feeling and meaning of the primary color.
- Accent color: Burnt orange (#D35400). Provides a warm, eye-catching call to action.
- Body and headline font: 'PT Sans' sans-serif for a modern and clean aesthetic that ensures readability across different screen sizes.
- Use simple,big, intuitive icons to represent different job categories and actions. Ensure icons are consistent and easily recognizable.
- Maintain a clean and organized layout. Prioritize key information such as job descriptions, pay rates, and worker skills.
- Use subtle animations and transitions to enhance user experience without being distracting. For example, loading animations or smooth transitions between screens.
